# P0b Slice 1 — Users Flow Wizard + Service Model + Subscription URL

Scope: **wizard UX** (replaces single-form UserForm) + **Service model** (named bundle: chains+protocols+exit-pin+MTProxy defaults) + **`/sub/{token}` subscription endpoint** (raw + base64 link-list) + **User schema additions** (DataLimit/ExpireStrategy/SubscriptionToken/Status — added, quota NOT enforced yet).

**Deferred:** quota enforcement poller (V2Ray stats API) → P0b-2. Per-user destination routing render (Service.RoutingPresetIDs → BuildRoutingSection) → P0b-3 (stored-not-rendered this slice, labelled clearly in UI). Clash YAML / sing-box JSON sub formats → later.

All audit + rationale in `docs/PROGRESS.md` §15 (P0a egress) and the design agent output. Decisions resolved: single-form wizard with DaisyUI steps + minimal JS toggle (matches `presets.templ` inline-toggle precedent); lazy token backfill (no migration #2); `ComputeStatus()` method as single source of truth; Service in `PanelSettings.Services json.RawMessage` (mirrors `CustomPresets`).

## A. Data model (`internal/domain/model/panel.go`)

**New `Service` struct** (after `PanelSettings`, before `SSHKeyEntry`):
```go
type Service struct {
    ID                 string            `json:"id"`
    Name               string            `json:"name"`
    Description        string            `json:"description,omitempty"`
    ChainNames         []string          `json:"chain_names,omitempty"`
    DefaultExitByChain map[string]string `json:"default_exit_by_chain,omitempty"` // chain→ChainNode.ID
    Protocols          []string          `json:"protocols,omitempty"`
    RoutingPresetIDs   []string          `json:"routing_preset_id,omitempty"`    // stored, NOT rendered (P0b-3)
    MTProxy            struct {
        Enabled    bool     `json:"enabled,omitempty"`
        Domain     string   `json:"domain,omitempty"`
        OrderIndex int      `json:"order_index,omitempty"`
        NodeIDs    []string `json:"node_ids,omitempty"`
    } `json:"mtproxy,omitempty"`
}
```
`PanelSettings.Services json.RawMessage` (mirrors `CustomPresets` at `panel.go:88`).

**User additions** (all `omitempty`, additive — NO migration needed to load old stores):
`DataLimit int64`, `DataLimitResetStrategy string`, `ExpireStrategy string` (`fixed_date|start_on_first_use|never`), `UsageDuration int64`, `ActivationDeadline time.Time`, `SubscriptionToken string`, `Status string`, `ServiceID string`, `UsedTraffic int64`, `LifetimeUsedTraffic int64`, `FirstUseAt time.Time`.

**`User.ComputeStatus()` method** — returns `disabled` (if !Active) / `expired` (IsExpired) / `on_hold` (start_on_first_use + FirstUseAt zero) / `active`. Called at save + list time. (`limited` needs P0b-2 poller.)

**Migration:** NO migration #2 — lazy token backfill on first `/sub/` fetch + mint at create-time. `currentSchemaVersion` stays 1.

## D. `/sub/{token}` endpoint (public, no auth)

- Register `mux.HandleFunc("GET /sub/{token}", s.handleSubscription)` directly on mux in `Server.Register` WITHOUT `s.auth` (precedent `/static/`, `/`, `/health`). GET passes CSRF (safe-method bypass at `csrf.go:23-26`).
- `handleSubscription`: `r.PathValue("token")` → `store.GetUserBySubscriptionToken(token)` (new linear-scan helper near `GetUser` `:512`, 16-byte url-safe token collision-free). Unknown → 404. Honor `ComputeStatus()` (expired/disabled/limited → 404). Lazy token backfill + start_on_first_use `FirstUseAt` stamp (no enforcement, just record).
- Format: `?format=raw|base64`; default by User-Agent (`v2rayng/nekoray/nekobox/shadowrocket/sing-box` → base64, else raw). Reuse `buildConnectionLink`/`buildStandaloneLink` via new shared `collectUserLinks(u, st)` (extract from `handleUserConfig:344-413` + `handleUserQR:693-710` — DRY refactor, no behaviour change). base64 = join `\n` + base64.StdEncoding. `Content-Type: text/plain; charset=utf-8`, `Cache-Control: public, max-age=60`, `Content-Disposition: attachment; filename="sub"` (base64) / `inline` (raw).
- `GenerateSubscriptionToken()` in `cryptogen.go` (mirror `GenerateTUICPassword:140-148`, url-safe base64 16 bytes, error-returning).

## H. Risks (flagged)

1. `Service.RoutingPresetIDs` stored-not-rendered — UI labels it clearly ("applies on next deploy — P0b-3"). `BuildRoutingSection` (`presets.go:275-335`) consumes `preset.Routing` geosite names, not `ROUTING_PRESETS` domain lists; per-user-destination render is P0b-3.
2. Subscription URL host uses `r.Host` (browser-visible, correct behind reverse-proxy if proxy sets Host/X-Forwarded-Host); fallback `s.ActiveListenAddr`. `/sub/{token}` itself is host-agnostic.
3. Public `/sub/{token}` bypasses `s.auth` → no `no-store` Cache-Control (correct — sets own `max-age=60`). No i18n context needed (returns config blob).
4. `limited` Status never set this slice (needs P0b-2 poller). `ComputeStatus` covers active/disabled/expired/on_hold only.
5. Token uniqueness: create-time `GetUserBySubscriptionToken(t)` not-found check (cheap insurance, 2^96 entropy).

**No e2e / VPS changes this slice** — pure UI + handlers + model. Egress (P0a) unaffected and deferred.
